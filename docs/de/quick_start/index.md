# Schnellstart

Supernotify lässt sich installieren und nutzen, ohne eine Zeile YAML zu schreiben. Diese Seiten dauern etwa zehn Minuten:

1. [Installation](installation.md)
2. [Die erste Benachrichtigung senden](first_notification.md)
3. [Wie es weitergeht](next_steps.md) - angefangen mit einer Automatisierung und einem Dashboard
4. [Grundkonzepte](basic_concepts.md) - die wichtigsten Ideen und Begriffe erklärt

Außerdem gibt es [fortgeschrittene Konzepte](advanced_concepts.md) und viele [Rezepte](../../recipes/index.md) zum Ausprobieren.

Wenn es Ihnen am Ende nicht zusagt, hilft die Anleitung zum [Entfernen](removing.md) beim Aufräumen, und wenn Sie mögen, [hinterlassen Sie eine Notiz](https://github.com/rhizomatics/supernotify/discussions/new/choose), was für Sie nicht funktioniert hat.
