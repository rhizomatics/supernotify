# Supernotify को हटाना

HACS मेनू में `Supernotify` चुनें और `...` मेनू से `Remove` चुनें।

### कॉन्फ़िगरेशन की सफ़ाई { #cleaning-up-config }

1. `config` डायरेक्टरी में हाथ से बनाई गई YAML फ़ाइलें जस की तस रहेंगी। अगर पक्का हो कि उनकी दोबारा ज़रूरत नहीं पड़ेगी, तो उन्हें खुद हटा दें।
2. आर्काइव की गई सूचनाएँ बनी रहेंगी, डिफ़ॉल्ट रूप से `/config/archive/supernotify` डायरेक्टरी में, जब तक कुछ और कॉन्फ़िगर न किया गया हो। ज़रूरत हो तो इस डायरेक्टरी को हटा दें।
3. अगर कैमरे या इमेज अटैचमेंट इस्तेमाल किए गए हों, तो मीडिया फ़ाइलें रह सकती हैं, डिफ़ॉल्ट रूप से `/config/media/supernotify` डायरेक्टरी में, जब तक कुछ और कॉन्फ़िगर न किया गया हो। ज़रूरत हो तो इस डायरेक्टरी को हटा दें।
4. टेम्पलेट रह सकते हैं, डिफ़ॉल्ट रूप से आपकी Home Assistant कॉन्फ़िग डायरेक्टरी के अंदर `supernotify/templates` डायरेक्टरी में, जब तक कुछ और कॉन्फ़िगर न किया गया हो। ज़रूरत हो तो इस डायरेक्टरी को हटा दें।
