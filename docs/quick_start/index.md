# Quick Start

Supernotify can be installed and used without writing any YAML. These pages take about ten minutes:

1. [Installation](installation.md)
2. [Send your first notification](first_notification.md)
3. [What to do next](next_steps.md) - starting with an automation and a dashboard
4. [Basic concepts](basic_concepts.md) -  the main ideas and terminology explained

There are also [advanced concepts](advanced_concepts.md) plus lots of [recipes](../recipes/index.md) to try out.

If you don't end up liking it, then use the [removal](removing.md) guidance to clean it up, and if you can, [leave a note](https://github.com/rhizomatics/supernotify/discussions/new/choose) on what didn't work for you.
