# Help and Support

If you can't find an answer here, try the [GitHub Discussions](https://github.com/rhizomatics/supernotify/discussions) where you can find advice other people requested, or raise your own request.

You might also find that one of the [Recipes](../recipes/index.md) is close enough to what you want, or has a technique that can be applied.

If you think its a bug, raise a bug request, or see if anyone else has the same problem at the [GitHub Issues](https://github.com/rhizomatics/supernotify/issues) page.
